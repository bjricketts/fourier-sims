# Fourier-sims

This repository contains the python scripts for generating simulated light curves to show the effects of 
calculating the cross-spectrum between two light curves of differing statistical properties (different 
power spectra). Figures generated by this script were used in X-ray timing signals and phase lags in 
X-ray binaries I. Simple simulated signals produce non-linear phase lags (Ricketts and Marcel, 2026). 

## Requirements
- numpy
- stingray
- matplotlib
- ndspec
- scipy

## How to generate paper plots

All plots are generated via a CLI interface with QPO sims. There are models for each plot/model in the
paper which are selected from the following models:

- damping
- coherent_sum
- resonance
- hidden
- multi_incoherent
- multi_coherent
- multi_multiplicative
- fm
- count_rate_fm
- enevelope_qpo

By default, figures are outputted into a figures subfolder. Thus to generate the figures seen in the 
paper, one should perform the following commands:

```
mkdir -p figures
python qpo_sims.py damping          --outdir figures --seed 0   # Fig. 1
python qpo_sims.py coherent_sum     --outdir figures --seed 0   # Fig. 2
python qpo_sims.py hidden           --outdir figures --seed 0   # Fig. 4
python qpo_sims.py multi_incoherent --outdir figures --seed 0   # Fig. 6 (a)
python qpo_sims.py multi_coherent   --outdir figures --seed 0   # Fig. 6 (b)
```

All models default to the parameters used in the paper. To run all the models in the paper, one can 
simply run the following command:

```
mkdir -p figures
python qpo_sims.py all
```

## Bispectra

`bispec_sims.py` runs every model above with its paper defaults and computes bispectral
diagnostics with the stingray bispectrum implementation (main branch, direct Fourier estimator):
the band 1 and band 2 bispectra and the cross-bispectrum X1(f1) X1(f2) X2*(f1+f2). Stingray must be
installed from main:

```
pip install "git+https://github.com/StingraySoftware/stingray.git@main"
```

Light curves are rebinned to 1/64 s and split into 16 s Hann-tapered segments (64 segments). The
taper is needed: above a high-Q QPO the PSD falls faster than the sidelobes of a rectangular window,
and the resulting leakage produces spurious bicoherence (try `--window none`). Squared bicoherence
(Kim & Powers) is averaged over 5% log-frequency cells and compared with a 99% threshold calibrated
on white-noise light curves with identical segmenting and taper. No Poisson correction is applied;
Poisson white noise at these count rates passes the null test at ~1%.

Each run writes `{name}_bicoherence_maps.png` (2D log10 b^2 and biphase; for the
rms/depth sweeps the biphase goes in a separate `{name}_biphase_maps.png`) and
`{name}_bicoherence_slices.png` (b^2(f, f), and b^2 and biphase in a QPO-width band of f2 around the
reference frequency). Runs map onto the paper figures as follows:

```
mkdir -p figures/bispec
python bispec_sims.py damping              # Fig. 2
python bispec_sims.py resonance            # Fig. 3
python bispec_sims.py coherent_sum         # Fig. 4
python bispec_sims.py hidden               # Fig. 5
python bispec_sims.py multi_coherent       # Fig. 6
python bispec_sims.py multi_incoherent     # Fig. 7
python bispec_sims.py multi_multiplicative # Fig. 8
python bispec_sims.py fm                   # Fig. 9
python bispec_sims.py fm_phase             # Fig. 10
python bispec_sims.py fm_offset            # Fig. 11
python bispec_sims.py count_rate_fm        # Fig. 12
```

or `python bispec_sims.py all` (~10 min, ~0.7 GB peak). Other options: `--dt`, `--segment`,
`--rebin` (0 = native resolution), `--max-cols`, `--ext pdf`, `--save-npz`.

Each run also writes `{name}_fourier.png` (power spectra, cross spectrum, phase lag and
coherence, all cases overlaid) and a multi-page `{name}_report.pdf`: an overview page, then
one page per case with the light curves, dynamical power spectra of both bands, the
second-order Fourier products, and the band-1 and cross bicoherence and biphase maps
(`bispec_report.py`; skip with `--no-report`). `--freq-scale linear` switches every
frequency axis to linear (maps then use native, equal-width bins by default).

## Biphase models

`bispec_biphase.py` simulates couplings between a flux component and a QPO that give
structured biphases on either side of the QPO, and compares them with the sideband
predictions in `biphase_models.md`:

```
python bispec_biphase.py fm_response --outdir figures/biphase
```

It writes the same Fourier, map, slice and report outputs as above, plus
`{name}_side_biphase.png`, the measured lower- and upper-side biphases against f1 with the
predictions.
